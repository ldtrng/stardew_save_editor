# ASO Research: Stardew companion (tracker + save editor), pre-launch

**Store:** Google Play
**Package:** io.ld2t.stardew_save_editor (not yet published)
**Research date:** 2026-10-14
**Brand tier (ours):** Challenger. New app, no ratings, no brand awareness, so every character and screenshot has to work for discovery.
**Method:** Public Play listing pages (en_US/US plus the 12 target `hl` locales) and Play search result pages for 8 queries, fetched 2026-10-14. Google web autocomplete for 13 languages. Competitor screenshots checked visually. Listing text was treated as untrusted data.

> Search volume, keyword difficulty, and install estimates need paid tools (AppTweak, Sensor Tower, MobileAction). Every volume or competition label below is a qualitative estimate based on SERP composition, autocomplete presence, and competitor install ranges.

## 1. Market analysis

### 1.1 Niche shape

- The niche is small. Every Stardew query (`stardew`, `stardew valley guide`, `stardew tracker`, `stardew checklist`, `stardew calendar`, `stardew bundles`, `stardew wiki`, `stardew save editor`) returns the same pool of about 18 fan apps, followed by unrelated farming games or utilities. A new app with exact-match metadata can rank on page 1 for long-tail queries quickly.
- The official game (com.chucklefish.stardewvalley) shows up in nearly every SERP, usually in position 1 to 4.
- **No app combines a polished tracker with a real save editor and a good rating.** The trackers (hiugo, Gunther's Library, Pocket Guide) do not edit saves. The editors (Div0, hellogametools, Chad Smith, CP Publisher) are either paid, poorly rated, abandoned, or thin on tracking. hellogametools ("Save Editor for Stardew Valley") is the closest hybrid, but it is rated 3.5 from 154 reviews.

### 1.4 Notable findings and opportunities

1. **"Save editor" queries are underserved.** The top results are a paid app (1K+), a 3.5-rated hybrid, and an abandoned 1.9-rated app. A well-rated editor can take this query.
2. **No competitor uses all 80 characters of the short description well.** hiugo uses 42, hellogametools 23, Gunther's 47.
3. **hiugo does not localize its title.** Gunther's does, but with a brand-first string. Localized titles with local game names (星露谷物语, 스타듀밸리, スターデューバレー, Стардью) are open.
4. **Ratings are the moat.** hiugo and Gunther's are both 4.9. We need an in-app review prompt after a positive moment (for example after a successful save edit or completing a bundle), and a crash and ANR rate well under the Vitals thresholds.
5. **Policy:** Competitors use "ultimate", "Free", "Best" and "award winning" in metadata. Avoid all of these (see CLAUDE.md and Google's metadata policy).
6. **Disclaimer pattern:** hellogametools and SteBakerDev open or close with "Unofficial fan-made ... not affiliated with ConcernedApe". Pickled Games cites the old Chucklefish trademark notice. ConcernedApe is now the rights holder.
7. **Features we have that the leaders lack:** an on-device save editor, save import into the tracker, heart tracking, automatic backups, and remixed bundles together with an editor.

## 3. App name

### 3.1 Trademark and policy constraints
- "Stardew Valley" is a registered trademark of ConcernedApe LLC. Google Play's impersonation and IP policy blocks titles that suggest an official product or endorsement. Rights-holder complaints, not automated filters, usually trigger removals, but a title that *starts with* the mark reads as a product name.
- Nominative use (naming the game only to say what the app works with) is the established fan pattern: "Gunther's Library for Stardew", "Save Editor for Stardew Valley", "Guide For Stardew". Apps that lead with the mark ("Stardew Valley Tracker", "Stardew Valley Save Editor") are live today and rank higher for exact queries, so the visibility gain is real.
- Play metadata rules also ban emoji, ALL CAPS, "free", "best", "#1" and "top" in titles. We also avoid "ultimate" and "official".
- **Matching rule observed in the SERPs:** the app with the query noun in its title wins that query ("Bundle Guide" wins "stardew bundles", "Save Editor" wins "stardew save editor", "Tracker" wins "stardew tracker"). Our title should contain **Stardew + Tracker + Save Editor**, which are the two highest-intent nouns for our feature set.

### 3.2 Candidates (≤30 characters including spaces)

| # | Title | Chars | Search visibility | IP risk | Notes |
|---|---|---|---|---|---|
| 1 | **Tracker & Save Editor: Stardew** | 30 | High: has stardew, tracker, save editor | Low-Med: descriptive words first, the game named only as the subject | **Recommended** |
| 2 | Stardew Tracker & Save Editor | 29 | Highest: exact phrases "stardew tracker" and "stardew save editor" | Med: "Stardew …" reads like a brand name | Use it as a Store Listing Experiment variant once the app has ratings |
| 3 | Tracker & Editor for Stardew | 28 | Med: loses "save", so it is weaker for "stardew save editor" | Low: textbook nominative "for" | Safe fallback if the title is ever challenged |
| 4 | Valley Companion for Stardew | 28 | Low-Med: only "companion" and "stardew" | Low | Brand-led and matches the current manifest label, but wastes the title on a brand with no awareness yet |
| 5 | Tracker & Save Editor for SDV | 29 | Low: "SDV" has little search volume, so "Stardew" is only in the description | Lowest: no mark in the title | Fallback only if Play ever rejects any use of the mark |

### 3.3 Recommendation
**"Tracker & Save Editor: Stardew" (30/30).**
- It covers every high-intent token in the strongest-weighted field: *stardew* (all queries), *tracker* (hiugo's main query, 50K+ app), *save editor* (the weakest-defended query in the niche), and *editor* alone.
- Leading with the function and naming the game after the colon is nominative in spirit. It reads as "a tracker and save editor for Stardew" and not as "the Stardew tracker". Combined with the disclaimer in the first lines of the description, this keeps the listing clearly unofficial.
- It does not duplicate any existing title. hellogametools already uses "Save Editor for Stardew Valley", and copying it would confuse users and reviews.
- It leaves the short description free for different keywords (checklist, bundles, gifts, calendar, Stardew Valley written in full).

### 3.4 Launcher name (≤12 chars, shown under the icon)
- **Recommended: "SV Companion" (12).** Fans recognize "SV" as the game's abbreviation, it does not spell out the mark, and it keeps the "Companion" brand already in the manifest.
- Alternative: "Farm Tracker" (12).
- The current `android:label="Valley Companion"` is 16 characters and gets truncated ("Valley Compa…") on most launchers. Change it in `android/app/src/main/AndroidManifest.xml`. Localized launcher names can go in `res/values-xx/strings.xml`, but "SV Companion" works in every locale.

## 7. Category, tags and conversion

### 7.1 Category
- **Recommended: Tools.** hiugo (the 50K+, 4.9 leader), Div0, hellogametools and SteBakerDev are all in Tools. A save editor is a utility, and Tools is where Play's "similar apps" clusters our main competitors. That drives the "Similar apps" and "You might also like" placements. The category's average CVR is about 36.8% (Utilities & Tools benchmark), above the Play average of 27.3%.
- Alternative: **Books & Reference** (Gunther's, Pickled, Pocket Guide). It fits pure guides, but it undersells the editor and puts us next to wiki-style apps. Re-check in a Store Listing Experiment only if Tools traffic disappoints.
- **Do not** list the app as a Game. It would compete with real games and trigger stricter game-content review.
- **Content rating:** answer the IARC questionnaire honestly (no violence, no user-generated content; ads present). The expected result is Everyone or PEGI 3. Make sure the AdMob content filter is set to G or PG.

### 7.2 Tags (Play Console → Store settings → Tags, up to 5)
Choose the closest available tags in this order: **Guide / Walkthrough** (or "Game companion" if offered), **Tools / Utilities**, **Calendar / Planner**, **Checklist / To-do**, **Reference**. Tag names vary by Console version, so pick the nearest equivalents. Do not use game-genre tags (Simulation, Farming), because they mislabel the app as a game.

### 7.3 Conversion notes
- **Icon:** the current 512px icon must not use ConcernedApe art, the game logo, or a recognizable game sprite (chicken, Junimo, the Stardrop) copied from the game. Use original pixel art in the same spirit, for example a parchment checklist with a quill and a small wrench or pencil, set on the farm-green palette, with bold silhouettes readable at 48dp and no text. Test it at launcher size next to hiugo (white and green) and Gunther's (wood book). A warm wood or parchment icon with a single green check mark stands out.
- **First 3 screenshots:** (1) overview hero, (2) save editor, (3) gifts. Captions must read at thumbnail size: 3-5 words, high contrast. Do not show the official logo. Show only UI and our own pixel art.
- **Preview video (15-30 s, works without sound):** 0-3 s farm overview with progress bars filling. 3-8 s tap a villager to see loved gifts and today's schedule. 8-14 s open the save editor, change money and skill level, and show the "Backup saved" toast. 14-20 s Import a save and watch the checklist tick itself. 20-25 s calendar and bundles. End card: title text, no CTA. Record screen captures only. Do not use game footage, which is ConcernedApe's copyrighted material and a policy risk.
- **Ratings strategy:** call the In-App Review API after positive moments (a successful save write, an import that completes, finishing a bundle), never on launch and never after an error. hiugo and Gunther's both sit at 4.9, so a 0.4-star gap would cost about 25% of installs from the same SERP.
- **Ads:** keep banners off the editor's write/confirm flows and avoid interstitials around save operations. Competitor reviews show ads drive 1-star reviews in this niche. The description promises "Supported by ads. No subscription, no trial period." Keep that promise exact.
- **Trust signals:** keep the disclaimer in the first lines. Add a Data safety form stating that save files stay on the device and nothing is uploaded, which is true as long as only AdMob collects data. Name the developer consistently.
- **Policy hygiene:** before every Console paste, run `grep -n -i "free\|best\|#1"` (CLAUDE.md rule) or rerun the verification script.
